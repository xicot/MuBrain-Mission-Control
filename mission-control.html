⌨️ Commands Reference

All available commands for content approval, system control, and automation

📱 Content Approval Commands

Use these in Telegram/WhatsApp to approve/reject content

/approve [post_id] → Approve specific post (e.g., /approve POST-005)
/approveall → Approve all pending posts at once
/reject [post_id] [reason] → Reject with feedback (e.g., /reject POST-005 "Too long")
/modify [post_id] [changes] → Request specific changes

📊 Status & Monitoring Commands

Check system status and content queue

/pending → Show all posts waiting for approval
/today → Show posts scheduled for today
/week → Show this week's full schedule
/performance → Show last 7 days analytics

⚡ System Control Commands

Emergency and control commands

/pause → STOP all auto-publishing immediately
/resume → Resume auto-publishing
/status → Check system health status
/delete [post_id] → Cancel scheduled post
/reschedule [post_id] [new_time] → Change post time (e.g., /reschedule POST-005 "2025-03-05 14:00")

📈 Reporting Commands

Generate and request reports

/report → Generate weekly performance report
/metrics → Show current funnel metrics
/leads → Show recent lead activity

🚀 Quick Reference

Daily Workflow:
1. Check morning brief (7:30 AM)
2. Review pending: /pending
3. Approve: /approveall
4. Done!
Emergency:
Stop everything: /pause
Wrong post published?
Reply immediately with /pause
